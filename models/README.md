This directory stores trained model artefacts.

Files are generated by running:
    python src/model.py

Contents:
  - aavail_best_model.joblib  : Serialised sklearn Pipeline (best model).
  - model_metadata.json       : Training metadata including:
      * model_name      : Winning model identifier.
      * trained_at      : ISO-8601 UTC timestamp.
      * feature_cols    : Ordered feature column names used for training.
      * cv_results      : Cross-validation metrics for all candidate models.
      * best_cv_metrics : MAE, RMSE, MAPE, R² for the selected model.
